# ADR 0018 — policy-gated autonomous shopper control

Status: Accepted for planned Phase 13 implementation.

## Context

GhostShopper currently executes a fixed deterministic `PURCHASE_JOURNEY`. AI is post-run analysis only and has no browser tools.

The product direction adds exploratory mystery shopping. Giving a model unrestricted Playwright access would violate existing safety, reproducibility, and audit boundaries.

## Decision

Add autonomous shopping through a **closed semantic control plane**.

The model receives a sanitized, bounded observation and returns one structured decision from a code-owned action vocabulary.

For page interactions, the model references opaque candidate IDs generated by the browser observation layer. Candidate IDs are scoped to one observation and are not selectors.

Every proposed decision passes:

1. schema validation;
2. deterministic state/policy validation;
3. budget validation;
4. the existing browser/network safety boundary;
5. safe execution and structured recording.

The model never receives a Playwright `Page`, unrestricted tools, selector execution, arbitrary URL navigation, or script execution.

Checkout initiation remains terminal. Payment submission remains prohibited.

The existing deterministic journey remains separate and unchanged.

## Consequences

Positive:

- exploration can be dynamic without making the model a security boundary;
- browser behavior remains testable with deterministic negative cases;
- prompt injection cannot directly grant new browser capabilities;
- paths are auditable and can later support reproduction;
- deterministic monitoring keeps its repeatability.

Costs:

- the observation/candidate layer is additional engineering;
- some storefront interactions will be unsupported until represented by semantic actions;
- candidate expiry requires careful state handling;
- model capability is intentionally narrower than generic computer-use agents.

## Follow-up

Phase 13 is decomposed in `../docs/tasks/PHASE_13_AUTONOMOUS_SHOPPER.md`.

Any future change that permits payment, customer authentication, arbitrary code/selectors, broader network access, or direct model browser control requires a new explicit ADR.
